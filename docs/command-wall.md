# Cinematic Command Wall

The Command Wall turns a CyberStage timeline into a large-screen operational story without changing the underlying simulation.

## Open the wall

Use the **COMMAND WALL** button in the director console or press `W`. The ordinary topology and the wall share the same scene and timestamp, so switching views never restarts the take.

Press `V` to cycle camera treatments:

| Shot | Purpose |
| --- | --- |
| `AUTO` | Follows the current phase and cuts between the other shots automatically. |
| `OVERVIEW` | Establishes the scene, phase ladder, system lanes, and current cue. |
| `CONTEST` | Emphasizes pressure, contested authority, and the active incident beat. |
| `CONTAINMENT` | Emphasizes defensive controls and protected systems. |
| `RECOVERY` | Emphasizes restoration, verification, and continuity. |

Phase, node, and previous/current/next cue controls are interactive. Selecting a phase or cue seeks the normal CyberStage timeline; selecting a node also updates the ordinary node inspector.

## Dedicated scene treatments

### Control Plane Eclipse

Displays a cinematic authority balance between a contested administrator session and trusted control, together with configuration-drift cells, write-fence state, and signed-baseline recovery.

### Cipher Furnace

Displays inert offline audit pressure as a candidate matrix. Any apparent match is shown only as **REDACTED**. The wall contains no secret material, candidate values, authentication request, or cracking procedure.

### Blackout Ledger

Displays a synthetic file-state matrix, affected/restored regions, an immutable restore wave, canary state, snapshot verification, and business-continuity status.

Every other built-in scene receives the generic wall, which still includes the phase rail, pressure and defense lanes, protected systems, metrics, telemetry, captions, and cue deck.

## Broadcast use

Command Wall works with **Broadcast Mode**. The combination removes the application chrome and director controls, leaving the wall as a clean 16:9 screen for recording, projection, streaming, or an on-set display.

A recommended workflow is:

1. choose a built-in scene;
2. open Command Wall;
3. choose `AUTO` for an autonomous take or lock a manual shot;
4. enable Broadcast Mode;
5. enter fullscreen;
6. play or scrub the existing timeline.

## Safety boundary

The wall is a renderer only. It derives every visual from the already-validated, frozen scenario and current timestamp. It does not add network transport, command execution, scanning, credential handling, external assets, or executable scene extensions.
